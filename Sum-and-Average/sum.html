Sum & Average

// The Prompt

Write a program that takes two numbers from the user and displays their sum and average.

// Output Console

// The Code

x = +prompt("Please enter your first number");
document.write("First Number: " + x + "<br/>");

y = +prompt("Please enter your second number");
document.write("Second Number: " + y + "<br/><br/>");

document.write("Sum is: " + (x + y) + "<br/><br/>");
document.write("Mean is: " + (x + y) / 2);
