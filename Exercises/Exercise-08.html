Life Calculator

// The Prompt

Write a program that takes the user's age and calculates how many days, hours, minutes, and seconds they have lived.

// The Code

                  
            const age = +prompt("How old are you?");

            const days = age * 365;
            const hours = days * 24;
            const minutes = hours * 60;
            const seconds = minutes * 60;

            document.write("You have lived for: <br><br>");
            document.write("- " + age + " years <br>");
            document.write("- " + days + " days <br>");
            document.write("- " + hours + " hours <br>");
            document.write("- " + minutes + " minutes <br>");
            document.write("- " + seconds + " seconds <br>");

// The Output
