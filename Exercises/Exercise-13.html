Magic Text Changer

// The Prompt

Create an h1 and a button. When the button is clicked, use JS to change the h1's text, text color, and background color.

// The Code

                  
            const myId = document.getElementById("myText");

            function swap() {
                myId.innerText = "I am a Frontend Developer!";
                myId.style.color = "#FF2D8F";
                myId.style.backgroundColor = "black";
            }
