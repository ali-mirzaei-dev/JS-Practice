Even or Odd

// The Prompt

Write a program that takes a number and determines if it is even or odd.

// The Code

                  
            const x = +prompt("Enter your number");

            document.write("Your number is " + x + "<br/><br/>");

            if (x % 2 == 0) {
                document.write("- your number is even");
            } else {
                document.write("- your number is odd");
            }
