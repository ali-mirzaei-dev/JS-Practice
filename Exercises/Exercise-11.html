Number Block Printer

// The Prompt

Write a program that uses a nested loop to print a block of numbers. The outer loop counts the rows (1 to 5). The inner loop prints the current row number 3 times on the same line.

// The Code

                  
            for (let i = 1; i <= 5; i = i + 1) {

                let c = "";
                for (let n = 1; n <= 3; n = n + 1) {
                    c = c + i + " ";
                }
                document.write(c + "<br/>");
            }
