Times Table Generator

// The Prompt

Write a program that uses a loop to print the multiplication table for the number 5 (from 1 to 10).

// The Code

                  
            const x = 5;

            for (let i = 1; i <= 10; i = i + 1) {
                let c = x * i;
                document.write(x + " * " + i + " = " + c + "<br/>");
            }
