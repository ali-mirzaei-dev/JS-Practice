FizzBuzz Loop

// The Prompt

Write a program that loops from 20 down to 0. If the number is even, print "Fizz". If the number is odd, print "Buzz". Add special formatting for the first and last numbers.

// The Code

                  
            for (let i = 20; i >= 0; i = i - 1) {

                if (i == 20) {
                    document.write("- Fizz" + " | ");
                } else if (i == 0) {
                    document.write("Fizz");
                } else if (i % 2 == 0) {
                    document.write("Fizz" + " | ");
                } else {
                    document.write("Buzz" + " | ");
                }
            }

// The Output
