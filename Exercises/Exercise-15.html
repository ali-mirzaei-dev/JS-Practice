The Highlighted List

// The Prompt

Create a list of items. When you click on an item, toggle its color between the accent pink and the primary background color using a function and the 'this' keyword.

// The Code

                  
            const myLi = document.querySelectorAll("li");

            function Highlighter(element) {

                if (element.style.color == "rgb(255, 45, 143)") {
                    element.style.color = "#F2F2F2";
                } else {
                    element.style.color = "#FF2D8F";
                }
            }
