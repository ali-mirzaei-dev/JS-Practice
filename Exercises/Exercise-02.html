Variable Swap

// The Prompt

Write a program that takes two numbers from the user and swaps their values.

// The Code

                  
            let x1 = +prompt("Please enter your first number");
            let x2 = +prompt("Please enter your second number");

            document.write("Your first number (x1) is: " + x1 + "<br/>");
            document.write("Your second number (x2) is: " + x2 + "<br/><br/>");

            let z = x1; 
            x1 = x2; 
            x2 = z;

            document.write("x1 after swap: " + x1 + "<br/>");
            document.write("x2 after swap: " + x2 + "<br/>");

// The Output
