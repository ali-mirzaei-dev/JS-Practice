Circle Calculator

// The Prompt

Write a program that asks the user for the radius of a circle, then calculates and prints the Diameter, Circumference, and Area.

// The Code

                  
            const r = +prompt("Enter your circle radius");

            const diameter = 2 * r;
            const circumference = 2 * 3.14 * r;
            const area = 3.14 * (r * r);

            document.write("- Diameter → " + diameter + "<br/>");
            document.write("- Circumference → " + circumference + "<br/>");
            document.write("- Area → " + area + "<br/>");

// The Output
