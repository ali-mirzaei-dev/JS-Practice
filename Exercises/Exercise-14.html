Dark/Light Mode Toggle

// The Prompt

Create a div and a button. When the button is clicked, use a function to check if the div has the "darkTheme" class. If it does, remove it. If it doesn't, add it.

// The Code

                  
            let myId = document.querySelector("#myDiv");

            function themeSwap() {
                if (myId.classList.contains("darkTheme")) {
                    myId.classList.remove("darkTheme");
                } else {
                    myId.classList.add("darkTheme");
                }
            }
