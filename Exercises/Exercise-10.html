Star Pyramid

// The Prompt

Write a program that uses a nested loop to print a pyramid of stars (5 rows high).

// The Code

                  
            for (let i = 1; i <= 5; i = i + 1) {

                let s = "";

                for (let n = 1; n <= i; n = n + 1) {
                    s = s + "*";
                }
                document.write(s + "<br/>");
            }

// The Output
